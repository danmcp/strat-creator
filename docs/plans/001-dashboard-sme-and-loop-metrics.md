# Plan: Dashboard Metrics - Empty SME Input & Refine Loop Count

## Goal

Add two new metrics to the strat-creator dashboard (strat-dashboard-0f1209.gitlab.io):

1. **STRATs passed with empty Staff Engineer / SME Input** - how many strategies achieved rubric-pass without any human corrections in the SME Input section.
2. **Refine/review loop count per STRAT** - how many refine/review iterations each strategy went through (local and CI) before passing.

## Context

Requested by Eder (2026-07-30). Tracked as RHAIFIRST-390.

The dashboard is generated by `scripts/generate-dashboard.py` from JSON data produced by `scripts/extract-pipeline-data.py`. The CI pipeline in the strat-dashboard repo clones strat-creator and runs the generator - all code changes are in this repo.

## Phases

### Phase 1: SME Input Detection (extract + dashboard)

No schema changes needed. Data already exists in `pipeline-data.json` strategy bodies.

#### Task 1.1: Add `has_sme_input` parser to `scripts/extract-pipeline-data.py`

Parse each strategy body for the `## Staff Engineer / SME Input` section. Detect whether it contains only the default template boilerplate or has actual content.

```python
def has_sme_input(body):
    marker = "## Staff Engineer / SME Input"
    idx = body.find(marker)
    if idx == -1:
        return False
    sme_section = body[idx + len(marker):]
    next_header = re.search(r'\n## ', sme_section)
    if next_header:
        sme_section = sme_section[:next_header.start()]
    sme_section = re.sub(
        r'\*Add technical corrections.*?from Jira\.\*',
        '', sme_section, flags=re.DOTALL
    )
    return len(sme_section.strip()) > 0
```

Add `"has_sme_input": has_sme_input(body)` to the strategy dict in `extract_strategy()`.

Files: `scripts/extract-pipeline-data.py`

#### Task 1.2: Add SME Input KPI card and table column to dashboard

In `scripts/generate-dashboard.py`:

- Count STRATs where `recommendation` is approve AND `has_sme_input` is false
- Add KPI card to Executive Summary: "N of M approved STRATs had empty SME Input (X%)"
- Add indicator column to the per-strategy table

Files: `scripts/generate-dashboard.py`

#### Task 1.3: Unit tests for `has_sme_input`

Test cases:
- Empty section (boilerplate only) -> false
- Section with real content -> true
- Missing section entirely -> false
- Boilerplate plus additional text -> true

Files: `tests/`

### Phase 2: Refine Loop Count - Instrumentation

#### Task 2.1: Add `refine_count` to strat-task frontmatter schema

Add `refine_count` (integer, default 0) to the optional fields in the strat-task schema.

Files: `scripts/frontmatter.py`

#### Task 2.2: Increment `refine_count` in strategy-refine skill

Increment the counter **only when the refine pass actually changes the strategy
body** - a no-op pass (no new input, nothing rewritten) must not increment. See
[ADR-0001](../decisions/ADR-0001-refine-loop-count-source.md) for why: the metric
is the regression signal for RHAIFIRST-325, whose fix makes no-input passes
no-ops. If the counter bumped on every invocation it would keep climbing after
325 is fixed and stop being a useful convergence signal.

```bash
# only after confirming this pass rewrote body content
python3 scripts/frontmatter.py set <path> refine_count=<n+1>
```

Files: `.claude/skills/strategy-refine/SKILL.md`

Note: this couples to RHAIFIRST-325. Until 325 lands, non-convergent passes
still rewrite the body (that is the bug) and correctly count. The gate matters
once 325's no-op behavior exists - implement the gate now so no rework is needed
then.

#### Task 2.3: Include `refine_count` in extracted data

Read `refine_count` from frontmatter and include it in the per-strategy dict output by `extract_strategy()`.

Files: `scripts/extract-pipeline-data.py`

### Phase 3: Refine Loop Count - Dashboard

#### Task 3.1: Count pipeline runs per STRAT (immediate fallback)

In `generate-dashboard.py`, count how many different pipeline runs contain the same `strat_id` across all loaded runs. This provides a CI-only iteration signal from existing data with no pipeline changes.

Files: `scripts/generate-dashboard.py`

#### Task 3.2: Add loop count KPI card and table column

- Add KPI card: "Avg Refine Iterations: N.N across K STRATs"
- Use `refine_count` from frontmatter when available, fall back to pipeline-run count
- Add "Iterations" column to per-strategy table

Files: `scripts/generate-dashboard.py`
